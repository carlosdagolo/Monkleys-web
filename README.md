# Monkleys

Sitio web de **Monkleys**: seguridad y soluciones tecnológicas para personas y negocios en Colombia.

🌐 **Sitio en vivo:** https://monkleys.netlify.app

## Nuestra app (en desarrollo)

Estamos construyendo una app para negocios de servicios: agenda, cobros, clientes, inventario y caja en un solo lugar, con la marca de cada negocio.

▶️ **Conoce la app:** https://monkleys.netlify.app/demo/

▶️ **Prueba la demo interactiva:** https://monkleys.netlify.app/demo/app/

La demo usa datos de ejemplo y no guarda nada. Puedes cambiar de rol (recepción, profesional, dueño, cliente) y de dispositivo (celular o PC).

## Cómo se publica

Netlify publica automáticamente cada cambio que llega a `main`.

| Archivo | Qué es |
| --- | --- |
| `index.html` | Página principal |
| `demo/index.html` | Landing de la app para negocios |
| `demo/app/index.html` | Demo interactiva (Barbería El Bigote) |
| `demo/media/` | Video corto de la demo que se ve en la landing |
